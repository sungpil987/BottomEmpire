# Bottom Empire — 밑바닥 제국

Godot 4.3 Android idle mining clicker.

## Implemented prototype
- Street tapping and passive worker income
- Infinite mine floors, gems, and upgradeable drill
- Tap / worker / drill progression
- Rebirth with permanent relic bonus
- JSON save and offline earnings
- Four tabs and procedural pixel-inspired scenes
- GitHub Actions debug APK pipeline

## Install
Go to **Actions → Build Android APK → latest successful run → Artifacts → BottomEmpire-Android-APK** and install the APK from the downloaded ZIP.

## Roadmap
This is an initial playable prototype, **not yet the requested premium pixel-art finished game**. Next steps include actual authored sprite sheets, animations, equipment, shops, locations, mining machines, achievements, audio and long-term balance testing.
